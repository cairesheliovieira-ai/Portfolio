# Portfólio - Hélio Caires

Site pessoal de **Hélio Junior Vieira Caires**, estudante de Ciência da Computação em Brasília. O projeto apresenta seu perfil, habilidades, projetos e informações de contato.

## O que você encontra no site

- **Início:** apresentação, áreas de interesse, formação, habilidades e acesso ao currículo em PDF. Também permite alternar entre a foto e a versão cartoon.
- **Projetos:** trabalhos de inteligência artificial, dados e desenvolvimento web, com filtros por categoria.
- **Contato:** links para GitHub e LinkedIn, e-mail e download do currículo.

Entre os projetos apresentados estão um assistente de voz com LLM na AWS, planilhas de análise de fundos e o VelocityNet, um teste de velocidade de internet.

## Tecnologias

O site foi desenvolvido com HTML, CSS e JavaScript, sem frameworks.

## Executar localmente

Abra `index.html` no navegador ou inicie um servidor local na pasta do projeto:

```bash
python3 -m http.server 8000
```

Acesse <http://localhost:8000>.
